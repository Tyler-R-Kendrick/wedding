How this stays out of the chat

Each value gets a fresh AES-256-GCM key (the variable name is the associated data); that key is wrapped with RSA-OAEP-4096 for every recipient above. Plaintext exists only in this tab and in the sandbox's .env, which agents are denied from reading. What lives here, in git, and in the chat is ciphertext, variable names, and lengths. Losing a private key makes its envelopes unreadable — reseal from this page. Full write-up: docs/ops/secrets.md.
