Proof older than 5 minutes · re-ask required

What re-asks

  • Changing the email on an invitation
  • Claiming a ride benefit
  • Deleting a travel profile
  • Any admin write

The window is five minutes from the last proof. It's enforced server-side in the capability pipeline, so hiding the button would not have been enough.
