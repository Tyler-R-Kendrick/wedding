Two complete design systems

The switcher is for guests, not just us

FLAG_DESIGN_SWITCHER is on by default, so anyone can move between the two kits. The choice rides a cookie, and ?theme= makes any link shareable in a chosen kit.

Gilded Hour

Art Deco. Cinzel over Josefin Sans, Big Shoulders for numerals; white Carrara marble ground, gold rules, square corners, engraved insets.

#1C1B18#C9A648#2E5B7B

Conservatory

Botanical. Gloock over Spectral, Cardo for numerals; creme herbarium paper, leaf greens, 8px radius, pressed-specimen rules.

#2A4430#7E9C5F#D4B24A

Use the Design control above the viewport — every scene in every lab re-renders in the other kit. Nothing about the markup changes; only which generated token block resolves.

Admin · lifecycle

Manual state always beats the clock

The calendar only ever suggests a state. An admin accepts or ignores it, and a preview never changes what the public sees.

Allowed transitions

Forward by one or more states, or back by exactly one — an undo, not a rewind. canTransition enforces it server-side.
