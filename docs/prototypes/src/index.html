Seven feature labs, one per shipped level

The platform is built through level 10 and has no public deployment yet, so each lab is a standalone harness for one feature area. Every lab renders the real seed content inside a device frame you can resize, and the wedding tokens are inlined verbatim from src/themes/<id>/theme.css — so switching between Gilded Hour and Conservatory shows you the two design systems as they actually ship, not an approximation of them.

Each lab opens on a 390px phone, because that is what the site is built for. Every scene carries a note strip naming the route, the capability behind it, and what is worth checking.

How to read a lab

Design

Switches which kit's token block the device resolves against. Nothing about the markup changes — that is the point of the theme engine. Try it on any scene.

Viewport

390 is the phone the site is designed for and where most guests will be. 768 and 1240 check that nothing collapses on the way up.

The note strip

Under each device: the route, the capability, the entitlement, and two or three specific things worth checking on that scene.

Hatched blocks

Every TODO(Tyler & Sara) is a fact only the couple can supply. They are drawn as placeholders on purpose — nothing plausible is ever invented to fill one.

Testing the real thing

These labs are static harnesses: no database, no capability pipeline, no server-side authorization. They are for judging the interface. To exercise the actual system:

npm run dev          # localhost:3000, auto-migrates and seeds PGlite
npm run verify       # typecheck, lint, unit, stylelint, design lint,
                     # detector, integration on PGlite, build
npm run test:e2e     # Playwright, needs BASE_URL

The labs are regenerated from the shipped tokens, so they cannot drift silently:

npm run design:sync && node docs/prototypes/build.mjs

Facts on every lab come from docs/design/brief.md and src/content/seed/*. Guest fixtures are the committed fictional households — Testhouse, Fixture and Solo — because real guest data never enters the repository.
